# Proyecto Analítico: Calidad de Servicio en RedConecta Telecom S.A.

## 1. Objetivos del Proyecto
Analizar la información operacional de los servicios de telecomunicaciones para evaluar el desempeño de la red, priorizar acciones de mejora en soporte técnico y medir el impacto de las incidencias en el cumplimiento de los Acuerdos de Nivel de Servicio (SLA).

## 2. Etapas del Análisis
- **Ingesta de Datos:** Carga del registro histórico centralizado (`dataset_set_D_telecomunicaciones.xlsx`).
- **Procesamiento y Exploración:** Evaluación de la carga operativa mediante el análisis de latencia, tickets de soporte y tiempos de resolución.
- **Generación de Reportes:** Creación de datasets segmentados para el Área de Soporte Técnico y el Área de Experiencia de Clientes.
- **Visualización:** Construcción de un *dashboard* exploratorio con indicadores clave para la gerencia.

## 3. Principales Resultados
- Se identificaron disparidades significativas entre regiones respecto a los tiempos medios de resolución de incidencias.
- Se evidenció que los aumentos de latencia y el volumen de clientes afectados impactan directamente en el no cumplimiento de los SLA.
- La segmentación de datos lograda permite ahora una asignación técnica de recursos mucho más eficiente.
